## CN2 到底是什么线路

CN2 是中国电信下一代骨干网的简称，AS 号是 AS4809，和大多数人平时走的老骨干网（AS4134，俗称 163 网）是两套并行体系。区别在路由策略上：163 网承载的是普通互联网流量，量大、优先级一般，晚高峰跨境拥塞很常见；CN2 定位是电信的商业级承载网，容量规划更充裕，跨境链路上的 QoS 优先级也更高，所以在电信宽带用户面前，CN2 的延迟和丢包表现通常明显更好。

对选 VPS 的实际意义就一句话：**如果你的用户主要用电信宽带访问你的服务，回程走 CN2 意味着晚高峰也不容易崩**。

但注意，CN2 内部还分档位，这是选购时最容易踩坑的地方。

### CN2 GT 和 CN2 GIA 的区别

市面上说的"CN2 VPS"其实混着两种东西：

- **CN2 GT（Global Transit）**：只有出境或某一段走 CN2，其余部分还是普通线路。比如机房本地接入是 CN2，但回程到大陆走的是 163 骨干，这种通常被叫做"假 CN2"或"单程 CN2"。
- **CN2 GIA（Global Internet Access）**：全程走 CN2，去程回程都在 CN2 网内跑，属于电信精品网最高等级。价格也最贵，通常只有阿里云、腾讯云、搬瓦工这类大渠道能拿到 GIA 资源。

### 一个常见误区：走 CN2 不等于走 AS4809

判断真假 CN2 最可靠的方法是看回程路由。在服务器上跑 `mtr` 或 `traceroute`，看数据包回到你本地电信宽带时，中间跳数是不是落在 `59.43.x.x` 这段 IP（CN2 骨干网使用这个网段）。如果回程全程 `202.97.x.x`（163 网关口），那不管商家怎么宣传，这条线路在电信用户面前就是普通 163 品质。

## 月付和年付怎么选

月付 VPS 的好处不是便宜——按年折算，月付几乎总比年付贵——而是**风险可控**。

- **新商家没建立信任前，坚持月付**：跑路风险是真实存在的，月付最多损失一个月的钱。
- **测试线路阶段用月付**：拿到机器先测回程是不是真 CN2、晚高峰表现如何，确认值这个价再考虑转年付或续费。
- **长期稳定用的机器选年付**：已经验证过质量的服务商，年付能省 30% 左右。

一个务实的策略是：先月付测一两个月，满意后转年付，两不耽误。

## 选购时的硬指标清单

下单前按这个顺序核对，能过滤掉大部分坑：

1. **确认线路等级**：GIA 还是 GT，回程是否走 `59.43.x.x`。商家页面不写清楚的，直接问客服要路由测试 IP。
2. **看带宽和流量是否匹配**：CN2 国际出口带宽成本高，低价大流量的套餐几乎必然超售。警惕"1Gbps 带宽 + 10TB 月流量"却只要 50 块这种配置。
3. **看是否支持 Ping/ Looking Glass**：靠谱的商家会提供测试 IP 和 Looking Glass 页面，让你先测再买。不给测试的，谨慎。
4. **确认是否需要实名**：大陆方向优化的线路越来越多要求实名，这个是合规要求，提前准备好身份信息。
5. **看退款政策**：有的商家支持开通后 24/48 小时无理由退款，有的只对质量问题退款。买之前看清条款，尤其是长周期订单。

## 几个高频疑问

**Q：CN2 VPS 一定比普通线路快吗？**
不一定。CN2 的优势体现在电信用户访问时的晚高峰稳定性。如果你的访问者主要是移动、联通用户，或者非大陆地区，CN2 的收益就没那么明显，没必要为此多花钱。

**Q：怎么验证买到的真是 CN2？**
拿到机器后，从你本地电信宽带对服务器跑 `traceroute`（注意方向是回程），看回程路径里是否出现 `59.43.x.x` 段。也可以用 `mtr` 持续观察丢包率。如果不达标，留存测试截图，作为申请质量退款的依据。

**Q：月付 VPS 续费会涨价吗？**
部分商家首月有优惠价，续费恢复原价。下单前看清是"循环优惠"还是"仅首次生效"，避免被首月价格误导。
